While the quest window is open

Today the words wait until you close the quest window, so they seem to start in the middle of the speech.

  1. Always show the words. Recommended. They start with the voice, whether the window is open or not. In the talking head they are part of the player, so hiding them looks broken. The duplicate text is fine: the window is the page, the subtitle is the voice.
  2. Hide only the bottom-of-screen line. Keep the words in the talking head, drop only the big cinematic line while the window is open, where it really sits next to the same text.
  3. Idea: follow along in the quest window. While it is open, the sentence being spoken is highlighted in the quest text itself, and the subtitle stays quiet. Charming, but it rewrites Blizzard's quest text on screen, so it is an experiment, not a default.
